# Claude Certified Architect - Foundations (CCAR-F) Prep

Welcome to the ultimate open-source preparation workspace for the **Claude Certified Architect – Foundations (CCAR-F)** certification. 

This repository contains everything you need to master Agentic Architecture, the Model Context Protocol (MCP), and Claude Agent orchestration.

## 📂 Repository Structure

The workspace is divided into three main components:

1. **`CCAR-F_Exam_Prep/` (The Web Portal)**
   A fully interactive, browser-based learning platform. It includes:
   - **Interactive Course:** 30 paginated lessons covering every official task statement with *runnable CLI terminal simulations*.
   - **Flashcard Engine:** 76 spaced-repetition flashcards.
   - **Practice Quiz:** 65 scenario-grounded practice questions.
   - **Mock Exam Simulator:** A strict 120-minute, 60-question simulator with a 100-1000 scaled score algorithm.
   - **Scenario Deep Dives:** Interactive decision trees for 6 production use cases.

2. **`CCAR-F_Sandbox/` (The Code Playground)**
   A collection of Python scripts, `CLAUDE.md` examples, and MCP configurations. Use this to physically practice building agentic loops, subagent delegates, and structured error handlers in your IDE.

3. **`Claude_Certified_Architect_Guide/` (The Official Docs)**
   The source-of-truth markdown blueprint detailing the exam logistics, policies, and scoring.

## 🚀 Getting Started Locally

You do not need to install Node, React, or any complex build tools to run the exam prep portal. It is built with vanilla HTML/JS/CSS.

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/yourusername/Claude-Code-Architect.git
   ```
2. Navigate to the Exam Prep folder:
   ```bash
   cd Claude-Code-Architect/CCAR-F_Exam_Prep
   ```
3. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

*To use the Sandbox scripts, you will need Python 3 installed on your machine.*

## 🌐 Deploying to GitHub Pages (Free Hosting)

Want to host this web portal on the internet so you can study from your phone or tablet? Because it's built with vanilla web technologies, you can host it for free using GitHub Pages in exactly 3 clicks.

1. **Fork** this repository to your own GitHub account.
2. Go to your repository's **Settings** tab.
3. Click on **Pages** in the left sidebar.
4. Under **Build and deployment**, set the **Source** to `Deploy from a branch`.
5. Under **Branch**, select `main` (or `master`), and change the folder from `/ (root)` to `/CCAR-F_Exam_Prep`.
6. Click **Save**.

Within a few minutes, GitHub will provide you with a live URL (e.g., `https://yourusername.github.io/Claude-Code-Architect/CCAR-F_Exam_Prep/`) where your personal exam portal is hosted!
